# qianminjun_firstrepository

我的第一个 Git 仓库，用来练习 Git / GitHub 的基本工作流。

## 这个仓库在做什么

- 学习 git add / commit / push / pull 的基本用法
- 记录学习过程中的笔记和小练习

## 常用命令

`ash
git status          # 看当前改了哪些文件
git add .           # 把改动放进暂存区
git commit -m "说明"  # 提交一次快照
git push            # 推送到 GitHub
git pull            # 把 GitHub 上的新改动拉下来
`

## 环境

- Git for Windows 2.54.0
- 默认分支：main
